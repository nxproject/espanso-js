espanso-js auto-loader

This page never calls the library. It adds one <script> tag, serves its snippets as JSON (auto-config.json), publishes page data for the dom variable, and listens to espanso:* DOM events. Try ;hi, ;sig, ;ref, ;today, ;bold (rich text is off, so it arrives as plain text), ;broken (fails to render, so the field is left as typed) and ;paste (clipboard is disabled, so nothing happens).
